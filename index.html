Download Planix 1.1.1 Codename "MerCur Extended"
Login with user planix and password planix
Install Planix to any disk/storage device (SSD, HDD, USB drive, SD/microSD card, etc.) using the following command: 
xzcat planix-1.1.1-aarch64.img.xz | sudo dd of=/dev/[target device] bs=4M status=progress conv=fsync
Replace [target device] with the name of the target device. For instance: sda, nvme0n1, ada, vda, etc.
WARNING: To avoid selecting the wrong device, run lsblk. Do NOT select the device containing your current operating system.
On most Linux systems, this is the device mounted at /(it could be /dev/root for you, make sure to double-check)
